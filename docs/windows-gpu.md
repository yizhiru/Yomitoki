# Windows GPU 本地翻译（未发布）

此功能位于 `feature/windows-gpu-translation` 分支，已发布的 0.1.0 仍为 CPU 版本。

## 使用

构建本分支后，打开「设置 → 本地翻译 → 翻译加速」：

| 模式 | 行为 |
| --- | --- |
| 自动（默认） | 检测兼容的 Vulkan 显卡，优先使用 GPU；没有可用设备、GPU 加载或推理失败时回退 CPU |
| GPU（Vulkan） | 明确使用检测到的 GPU；失败时显示错误，便于排查驱动与显存问题 |
| 仅 CPU | 使用独立 CPU 引擎，不初始化 GPU |

「检测显卡」会显示设备名称；检测不加载模型，也不自动下载模型。实际翻译后，界面显示正在使用的后端，以及模型确认卸载到 GPU 的层数。缓存命中只显示缓存提示，不把缓存速度算作 GPU 加速效果。

修改加速模式会取消当前查询并释放已加载模型，下次主动翻译时按新模式加载。模式会自动保存。模型仍使用原来的 Hy-MT2-1.8B Q4 文件，无需为 GPU 另下权重。

## 显卡与驱动

使用 [llama.cpp 的 Vulkan 后端](https://github.com/ggml-org/llama.cpp/blob/master/docs/build.md#vulkan)，适用于受该后端支持、具有兼容驱动的 NVIDIA、AMD 和 Intel 设备。实际兼容性以运行时检测和模型加载结果为准；拥有显卡本身不代表一定支持加速。

普通用户无需安装 CUDA Toolkit 或 Vulkan SDK；需有显卡厂商提供的兼容驱动。独立 CPU 与 Vulkan 引擎随安装包提供，互相隔离动态库，分别校验固定版本及 SHA-256。模型权重不随包分发。

显存占用包括模型、上下文和运行缓冲区，不能只按 1.13 GB 权重大小判断。速度取决于显卡、显存、驱动和选文长度，集成显卡不保证比 CPU 更快。

## 验证范围

自动化测试使用模拟引擎进程验证 GPU 选择、实际卸载日志判定、CPU 回退、故障重试、并发加载、取消和偏好保存。Windows 构建还检查双引擎打包、CPU 引擎启动、实际显卡枚举与安装后的界面。

通用 Windows CI 不提供可用于此模型的真实 GPU，测试也不下载模型权重。因此这些测试不能证明某张显卡的实际加速幅度；发布前仍需在真实显卡上验证模型加载、译文生成、显存占用与速度。
