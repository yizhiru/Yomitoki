# macOS 使用与实现说明

日语深度阅读。面向 macOS 的日语阅读软件，支持 PDF、EPUB、MOBI 阅读、词典释义、本地翻译、长句分析，以及围绕选文与大模型对话。生词本按词收集多条例句，并保留文件名与位置。

应用中文名为「读解」，项目名为 **Yomitoki**，项目文件夹为 `yomitoki`，日文名为「読み解き」，副标题为「日语深度阅读」。Yomitoki 来自「読み解き」，表达通过阅读理解文字、结构与含义。

为兼容旧版「文拾词」（Kotobahiroi）和「文脉」（Bunmyaku），应用标识 `local.bunmyaku.reader`、本地数据目录 `Bunmyaku` 和钥匙串服务标识保持不变，已有书架、阅读进度、生词本、模型与 API key 继续沿用。开发时可用 `YOMITOKI_DATA_DIRECTORY` 指定数据目录，并兼容 `KOTOBAHIROI_DATA_DIRECTORY` 和 `BUNMYAKU_DATA_DIRECTORY`；同时设置时按上述顺序优先选择。构建产物为 `dist/读解.app`，主程序为 `Yomitoki`。

## 下载与安装

从 [GitHub Releases](https://github.com/yizhiru/Yomitoki/releases) 下载最新版本。0.1.0 预编译安装包为 `Yomitoki-0.1.0-macos-arm64.zip`，适用于 Apple Silicon Mac，需要 macOS 14 或更新版本。解压后将「读解.app」拖入「应用程序」即可。发布页提供 `SHA256SUMS.txt`，可用 `shasum -a 256 -c SHA256SUMS.txt` 校验下载文件。

当前安装包采用本地 ad-hoc 签名，未经 Apple 公证。若 macOS 阻止启动，可在确认下载来源后，按系统提示前往「系统设置 → 隐私与安全性」允许打开。离线词典和翻译引擎已随 App 提供；本地翻译模型由用户自行下载。EPUB 和 MOBI 导入需要安装 calibre。功能与安装说明详见[更新记录](../CHANGELOG.md)。

## 导入格式

| 格式 | 读取方式 | 适用范围 |
| --- | --- | --- |
| PDF | 应用直接调用 macOS 的 PDFKit | 有文字层的 PDF。纯扫描件需要先做 OCR |
| EPUB、MOBI | 应用调用本机 [calibre](https://calibre-ebook.com/) 的 `ebook-convert` | 无 DRM 的电子书。calibre 需位于系统或用户的「应用程序」目录 |

阅读区显示提取并重排后的文字。PDF 保留原页码，EPUB 和 MOBI 按正文段落分节。词典离线可查，常用词有中文释义，广覆盖词典使用 [JMdict](https://www.edrdg.org/wiki/JMdict-EDICT_Dictionary_Project.html) 的英文释义。书架、进度和生词本保存在本机的 `~/Library/Application Support/Bunmyaku/library.json`。

界面采用白色主区域、浅灰侧栏与统一的灰蓝强调色，减少装饰标题和重复入口，统一使用系统无衬线字体。侧栏「书架」右侧的「导入」可导入文件。界面文字主要为 13–15 号，阅读正文默认 26 号，释义默认 20 号；正文仍可用阅读区右上角菜单调整，释义可在「设置 → 阅读显示」调整，已手动保存的释义字号会保留。生词本、对话、分析、翻译、设置与导出窗口使用同一套样式。

在「设置 → 阅读显示」中可切换「单击自动查词」，默认关闭，调整后即时生效并自动保存。关闭时，单击、双击或拖选都不会自动查询；选中文字后点击查询按钮才会查询。开启后，单击正文词语会自动查询离线词典，仍不会自动请求大模型或翻译。

正文使用普通文本，双击按 macOS 的规则选词，拖选可精确选择部分词、短语或整句，不会被查词分词覆盖。悬浮工具条按选文级别只显示对应功能：单词级显示「词典释义」「大模型释义」；句子级显示「本地翻译」「长句分析」；段落级显示「本地翻译」。所有有效选文均提供「大模型对话」。单句优先按句子级处理，多句或跨段选择按段落级处理。空白、标点或无效选区不显示菜单。工具条不抢走正文的键盘焦点；按 ⌘C 或使用右键菜单复制实际选中的原文。阅读区右上角与调用入口同步遵循级别限制。保存设置不会自动请求大模型。

右侧释义先显示英文释义，再显示中文释义。大模型结果会保留可匹配到的词典英文，中文部分显示模型给出的语境释义。在「设置 → 阅读显示」中，可将释义字号调整为 14–30 号，英文、中文、词源和原句使用所选字号，词头和读音相应放大；生词本详情、翻译译文与原文同步调整。字号即时生效并自动保存，重启后仍保留，无需保存模型设置。

侧栏与主内容之间、阅读正文与释义之间，以及生词本列表与详情之间的竖向分界线均可左右拖动调整宽度。三个分栏分别自动保存宽度，切换阅读和生词本或重启后会恢复；书架侧栏在两个页面共用同一宽度。窗口变小时会按可用空间暂时收窄，放大后恢复用户保存的宽度，不会用临时收窄的值覆盖偏好。各栏设有最小宽度，避免内容被压缩到无法使用。

查词结果、生词列表及详情会在读音下方显示本地 JMdict 的词性标记，例如名词、い／な形容词、一段／五段动词、自动词／他动词。显示标签依据 [JMdict 词性代码说明](https://www.edrdg.org/jmdict/jmdict_dtd_h.html) 转为中文，悬停可查看原始代码。同形异读词按读音匹配，没有词性时隐藏；旧收藏也会自动读取词典标记，不需要重新收藏或调用模型。

生词本列表在词语与读音下方显示已有的中文释义和已保存的大模型释义摘要，摘要最多显示两行，悬停可查看完整内容。中文优先使用已保存的词典释义，缺少时从随附中文词典补充；大模型释义从词条及各条语境中读取，相同释义只显示一次。详情中中文词典释义与大模型释义分别显示，大模型释义保留来源、词源及对应原句。没有或为空的释义栏目不显示，打开生词本不会触发模型调用。

## 选文对话

选中单词、句子的一部分、完整句子或段落后，点击悬浮工具条中的「大模型对话」，在右侧输入问题并发送，可继续追问。阅读区右上角的对话图标也能打开当前选文；没有选文时可继续上次对话。开关对话、选文和切换记录都不会自动请求模型。示例问题只填入输入框，仍需点击「发送」或按 ⌘↩。对话共用「设置 → 大模型」中的服务商、URL、模型名称和钥匙串 API key。

每次发送会附带当前对话固定的选中文本、该选文前后各最多 1600 字符的附近原文，以及该对话已有的问答。模型以自然语言回答，不限制为词典释义 JSON。同一次追问仍讨论原选文，重新选其他文字后点击「大模型对话」会打开对应的新对话；重新打开相同位置与文本会继续原对话。对话选文最多 8000 字符，单个问题最多 4000 字符，发送的问答合计最多 60000 字符；超出时提示缩短内容或清空当前对话，不自动截去历史。回复达到输出上限时会明确标注，可追问「请继续」。

支持停止回复、失败后重试及修改未回答的问题。切换书籍、页面、查词、分析、翻译或进入生词本时会停止请求并收起对话，迟到的旧响应不能覆盖当前对话。已发送的问答和选文保存在本机 `~/Library/Application Support/Bunmyaku/model-chats.json`，不包含 API key，重启后可继续。右侧顶部的「对话记录」菜单可切换记录或清空当前问答；未发送的草稿仅在本次运行中保留。记录损坏时保留原文件，新对话仍可在内存中进行。发送内容会交由配置的模型服务处理，费用由用户的 API 账户承担。

## 释义设置

查词结果和生词本的词条详情中提供「在 MOJi 中查询」按钮，使用当前词条原形搜索。优先通过 `mojisho://?search=…` 打开系统已注册的 MOJi 客户端；未安装客户端或启动失败时，使用默认浏览器打开 MOJi 的 `/searchText/…` 搜索页。两种方式都会对查询词进行 URL 编码。若系统也无法打开浏览器，应用会显示错误提示。

点击侧栏的「设置」，或打开应用菜单中的「设置…」，在「大模型」中配置主动使用的模型服务并保存。普通查词始终使用离线词典。

- **离线词典**使用随附的 JMdict 和简体中文释义，无需 API key。
- **大模型**仅在用户主动点击「大模型释义」、重试或重新释义时使用。服务商默认选择 DeepSeek，填入自己的 API key 即可使用，默认模型为 `deepseek-flash`，可修改模型名称。
- **自定义（OpenAI 兼容）**需要填写 API URL、模型名称和 API key。URL 支持服务商提供的 Base URL（例如 `https://api.example.com/v1`）或完整的 `/chat/completions` 地址，使用 Bearer 认证和 Chat Completions 消息格式。

远程模型接口优先使用服务商提供的 HTTPS 地址。为兼容仅提供 HTTP 的浙江实验室 MaaS 接口，应用已为 `i-nhi.zhejianglab.org` 配置 App Transport Security（ATS）HTTP 例外，接口可填写完整地址 `http://i-nhi.zhejianglab.org/maas/v1/chat/completions`。例外仅适用于这个域名，不包含其子域名；其他域名仍使用系统默认的 ATS 策略。HTTP 会明文传输 API key 和所选原句，请在信任的网络环境中使用。修改例外配置后，需要重新构建并重启应用才会生效。

未配置例外的 HTTP 地址可能被 ATS 拦截，应用会显示中文原因和处理建议。HTTPS 地址若重定向到 HTTP，或服务的 TLS 配置不符合要求，也可能触发 ATS 拦截。

API key 保存在 macOS 钥匙串中，服务商和模型配置保存在本机的 `~/Library/Application Support/Bunmyaku/settings.json`。主动进行大模型查询时会发送所选词语及附近原句，并使用用户自己的 API 账户计费。DeepSeek 查询使用非思考模式。生成的读音、中文语境释义及来源可随原句保存到生词本。查询失败时可以重试，也可以继续点击词语使用离线词典。

大模型释义会自动缓存到同一数据目录下的 `definitions.json`，不必先加入生词本。同一基本形和读音只保存一条缓存释义，常见动词、い形容词和な形容词的活用可通过词典校验后归一；例如「食べた」「食べない」「食べます」共用「食べる」词条。词典无法确认的词形由模型判断，原文中的词形、原句与位置仍保留在各条例句中。重启后缓存仍然有效；不同服务商、API 地址和模型的自动缓存分别保存。

再次进行大模型释义时优先复用已有模型缓存或生词本中已保存的模型词义，命中时不会读取 API key 或请求大模型。同一句在生词本中保存过的专用释义会优先于一般词条缓存；刚重新生成的同句缓存优先于旧收藏。复用结果会显示提示，可以点击「按当前原句重新释义」跳过缓存并请求模型，以处理一词多义和不同活用说明。重新生成后可用「更新这条例句」保存新的语境释义。

生词本按「基本形＋读音」合并；同形异读词保持分开。首次打开新版时会先将旧生词本备份到数据目录的 `backups` 文件夹，再归一可确认的旧词形并合并重复词条。与词条相同的例句释义在保存时省略，不同语境的释义单独保留；旧版文件仍可读取，导出内容不受精简存储影响。缓存文件无法读取时会保留原文件并提示，查询仍可继续。

大模型释义遇到片假名外来语时，会要求模型补充来源语言和原词拼写，并说明缩略形式或和制外来语的构词情况。词源无法确定时要求明确标注。词源说明在阅读侧栏和生词本中单独显示，可随例句保存，也可用原词搜索。旧版收藏数据可以继续读取，词源信息从新查询开始生成。

## 本地选文翻译（原型）

使用 [腾讯 Hy-MT2-1.8B Q4_K_M](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF) 将用户选中的日语句子或段落翻译成简体中文。App 已内置精简版 [llama.cpp](https://github.com/ggml-org/llama.cpp) 引擎，普通用户无需安装 Homebrew、命令行工具或选择引擎路径。模型采用 Apache 2.0 许可，权重由用户按需下载，不随 App 打包。首次准备：

1. 打开「设置 → 本地翻译」，可以看到「翻译引擎已内置」。
2. 点击「下载 Q4 模型」，通过 [HF 镜像](https://hf-mirror.com/tencent/Hy-MT2-1.8B-GGUF) 下载约 1.13 GB 的权重；或在镜像模型页面下载 `Hy-MT2-1.8B-Q4_K_M.gguf`，点击「选择已有模型…」。设置中也保留官方来源链接。支持取消下载；模型下载或文件选择后会在后台校验 SHA-256，校验通过才启用。不会自动下载或替换已有模型文件。
3. 回到阅读区，选中完整句子或段落，点击浮动工具条或阅读区上方的「本地翻译」。句子级另外提供「长句分析」，段落级只提供翻译；单词级只提供两种释义。右侧显示中文译文和所选原文，可用 ⌘C 复制。点击「返回词典」回到释义。

选文类型在本机按原文的句子、段落边界判断，不按字符长度判断。无句末标点时采用保守的日语分词规则识别句段；短句识别不出时可将句末标点一起选中。选中文字不会自动开始翻译，仍需用户点击按钮。

设置中的下载源可选「镜像 1 · HF 镜像」和「镜像 2 · ModelScope」，选择会保存在本机。ModelScope 固定使用腾讯官方仓库的版本 `ef1d40b8b315575d30d1eb6579996130b8fc0bb2`，文件大小和 SHA-256 与 HF 镜像一致。点击「快速测速」会依次请求两个 4 MB 文件片段，每个源最多等待 8 秒；成功时显示本次短测速度，失败或不支持片段请求时仅显示状态。测速可取消，下载期间暂停测速入口，测速结果仅保留在本次运行中。

下载固定为官方文件版本 `b27182d810fa3ceb6ed04e7c324c54e35c0d209c`，SHA-256 为 `dc5f44fcf1fa496ee7ad725982c0c8c553a4de00259b53af84c4b89fb0c06699`，默认地址为 `https://hf-mirror.com/tencent/Hy-MT2-1.8B-GGUF/resolve/b27182d810fa3ceb6ed04e7c324c54e35c0d209c/Hy-MT2-1.8B-Q4_K_M.gguf`。如镜像下载无法访问，可手动下载同一文件后选择。旧版已开始的下载使用原地址，需要取消后在新版重新下载。下载时会显示进度条、百分比及已下载/总大小；镜像未返回文件总大小时，使用固定版本的官方文件大小计算。下载完成后会显示完整性校验状态。模型下载是普通用户唯一需要外网的准备步骤；翻译过程无需 API key，不发送文本到远程服务，不会回退到云端模型。

App 按需启动自己的 `llama-server`，仅监听随机的 `127.0.0.1` 端口并使用临时认证，使用 8192 token 上下文、单并发和 Metal GPU 加速。原型一次最多接收 2000 个字符，实际分词过长时要求缩短选文，截断的输出不会缓存。首次加载模型需要等待；成功后复用模型，设置中可以手动释放内存，退出 App 会停止引擎。建议 Apple Silicon Mac 至少有 8 GB 内存，实际速度与内存占用取决于设备、引擎版本和选文长度。

切换书籍、页／节、生词本或查询词义时会取消正在进行的翻译，旧任务不能覆盖新结果。无自动翻译，选中、复制和保存设置都不会触发翻译。译文按完整选文、模型文件身份和提示词版本独立缓存，重启后仍可使用；可点击「重新翻译」跳过缓存。机器翻译仍可能误译省略主语、专名或长句。

本地配置位于 `~/Library/Application Support/Bunmyaku/translation-settings.json`，译文缓存位于 `translations.json`，通过 App 下载的模型位于该目录的 `models` 子目录。选择已有模型时直接使用原文件，不复制到 App 包。文件被移动或修改后需要重新选择校验。原型不包含 OCR、整书翻译或两份文档对齐。

内置引擎固定为官方 `b12097` 构建，打包时校验压缩包 SHA-256，只收集 `llama-server` 及其必要动态库，保留 CPU、Accelerate 和 Metal 后端。ARM64 运行文件约 29.8 MiB，另附许可和版本清单；不包含模型、训练工具或其他示例程序。引擎位于 `Contents/Helpers`，动态库位于 `Contents/Frameworks/llama`，均在 App 内签名并使用相对依赖路径。移动 App 后仍可定位引擎，不依赖 Homebrew 目录。旧版配置中的模型选择继续读取，外部引擎路径不再使用。引擎缺失时提示重新安装完整 App。

## 大模型长句分析

选中完整单句后，点击与「本地翻译」并排的「长句分析」。段落级只提供翻译，不显示长句分析；单词级只提供两种释义，入口也会再次校验选文。分析共用「设置 → 大模型」中已保存的服务商、API URL、模型和钥匙串 API key，不需要额外配置；不使用本地翻译模型。仅主动点击、重试或重新分析时发送所选单句给服务商，按该 API 账户规则计费。

右侧分别展示中文译文、主干结构、修饰层级、结构嵌套图解、语法难点及歧义/省略说明。提示词要求用 ［］、{ }、( ) 标记嵌套，用 ➔ 和 │、├、└、─ 标明修饰依存和中文成分标签；保留日语原句顺序，按实际语法画图，不照抄示例句。图解使用等宽字体，保留空格和换行，支持横向滚动与选择复制。其余说明使用设置中的释义字号。

分析按完整选文、服务商、接口、模型和提示词版本独立缓存在 `~/Library/Application Support/Bunmyaku/sentence-analyses.json`。命中时无需读钥匙串或访问 API；「重新分析」可跳过缓存。切换书籍、页节、生词本、查词或本地翻译会取消并关闭分析，过期结果不能覆盖新内容。截断输出或缺少主干、译文、结构图的响应会提示重试，不保存为成功缓存。一次最多选择 2000 个字符。语法和图解由模型生成，仍需结合原文判断。

长句分析在 DeepSeek 官方服务，以及浙江实验室 `i-nhi.zhejianglab.org` 的 DeepSeek V4 系列接口中显式发送 `thinking: {type: "disabled"}`。该 MaaS 接口默认启用思考模式，复杂结构图任务可能长时间只生成思考内容；非流式请求会等待完整输出，从而超时。关闭思考后仍保留全部分析字段及结构嵌套图，不改动 API 地址、模型或凭据；其他自定义服务不附加这个专用参数。

## 导出生词

在「生词本」右上角点击「导出生词」，选择 CSV 表格或纯文本 TXT，再选择全部生词、当前搜索结果或当前选中的词。单词始终导出，读音、中文释义、英文释义、外来语词源、释义来源、原文词形、原句、文件名及页码或节位置可分别勾选。初始勾选全部信息。

包含原句、原文词形、文件名或位置时，每条例句单独导出，并使用该例句保存的语境释义。仅导出词义时，同一个词的相同内容会合并。取消全部可选信息后，TXT 会成为每行一个单词的词表。CSV 使用带 BOM 的 UTF-8 编码，保留释义和原句中的引号、逗号及换行。

## 构建

需要 macOS 14 或更新版本，以及 Xcode 或 Xcode Command Line Tools（含 Swift 和 Python 3）。

```sh
./scripts/build.sh
open "dist/读解.app"
```

首次构建下载并校验固定版本的 JMdict。若已有同一版本的压缩包，可运行 `JMDICT_ARCHIVE=/绝对路径/jmdict.tgz ./scripts/build.sh`。生成的字典、缓存和应用包位于 Git 忽略的目录。

应用图标以展开的书页和阅读高亮表达「日语深度阅读」。源图位于 `Resources/AppIcon.png`；构建时由 `scripts/build_icon.sh` 使用 macOS 自带的 `sips` 和 `iconutil` 生成 16–1024 像素的标准及 Retina 图标，并打包为 `AppIcon.icns`，用于 Finder、Dock 和应用切换器。设计说明与生成提示词见 `Resources/AppIcon-design.md`。

构建同时下载并校验 `Resources/Runtime/llama-release.json` 固定的官方引擎压缩包，仅包含构建机器对应的架构（ARM64 或 x86_64）。缓存位于 `.build/runtime`；离线构建可用 `LLAMA_RUNTIME_ARCHIVE=/绝对路径/官方引擎压缩包.tar.gz` 指定同版本同架构文件，仍会强制校验。`scripts/bundle_llama.py` 收集动态依赖、改写为 App 内相对路径、检查最低系统版本和架构，并从内到外签名。`CODE_SIGN_IDENTITY` 可指定签名身份，默认使用本地 ad-hoc 签名。

构建后运行 `python3 scripts/verify_runtime.py`，检查引擎文件校验、完整依赖、签名、许可和无模型打包，并将 App 复制到含空格的临时目录，在不含 Homebrew 的 PATH 下执行引擎及设备枚举，验证可移动性和后端加载。

## 源码

- `Sources/Core.swift` 负责文件导入、日语分词、词典查询及原句提取。
- `Sources/ModelDefinitions.swift` 负责释义配置、钥匙串存取及 OpenAI 兼容模型调用。
- `Sources/LocalTranslation.swift` 负责按需下载与校验模型、本机引擎进程管理、选文翻译和独立缓存。
- `Sources/TranslationSelection.swift` 负责按原文句段边界判断选文是否可以翻译。
- `Sources/TranslationViews.swift` 负责本地翻译设置、下载进度与译文展示。
- `Sources/SentenceAnalysis.swift` 负责长句分析提示词、已有模型 API 调用和独立缓存。
- `Sources/SentenceAnalysisView.swift` 负责分节展示分析与可横向滚动的等宽结构图。
- `Sources/DefinitionCache.swift` 负责大模型释义缓存、生词本词义复用及强制重新生成。
- `Sources/NotebookExport.swift` 负责生词字段筛选、语境释义对应及 CSV、TXT 导出。
- `Sources/Reader.swift` 负责阅读界面、设置和生词本展示。
- `Sources/ReadingText.swift` 负责原生文本选择、单击查词、精确复制和不抢焦点的选词工具条。
- `Sources/PersistedSplitView.swift` 负责分栏拖动、独立宽度保存及窗口尺寸变化时的恢复。
- `Sources/ReaderState.swift` 负责普通词典查词、主动模型释义、查询取消和本地保存。
- `Resources/zh.tsv` 提供随应用附带的简体中文释义。

更新英文词典时，从 [jmdict-simplified Releases](https://github.com/scriptin/jmdict-simplified/releases) 取得新的英文 JSON 压缩包，更新 `scripts/build.sh` 中的版本和 SHA-256，并同步更新 `Resources/Dictionary/SOURCES.txt`。重新运行构建脚本即可生成新索引。衍生词典数据采用 CC BY-SA 4.0，许可和署名随应用分发。

运行 `./scripts/test.sh` 可检查模型请求格式、响应解析、错误处理、设置持久化、词形归一、缓存命中及重启读取、旧版生词本合并与精简存储、选词释义和生词导出。本地翻译测试检查精确选文、模型校验、译文缓存与重启、取消与过期结果、上下文限制，并用小型模拟引擎实际启动进程和本机 HTTP 服务。测试不下载模型，不评估真实模型的翻译质量。
